# Wayfarer — Personalized Travel Itinerary Planner

Frontend starter built with React, TypeScript, Vite, React Router, and Lucide icons.

## Requirements
- Node.js 20.19+ or 22.12+
- npm

## Run locally
```bash
npm install
npm run dev
```
Open the local URL printed by Vite (usually http://localhost:5173).

## Verify the production build
```bash
npm run build
npm run preview
```

## Current scope
- Dashboard with saved trips
- Trip creation form
- Demo itinerary generation (local sample data, not a real AI call)
- Itinerary detail view
- Delete trips
- Browser localStorage persistence

## Not connected yet
Authentication, FastAPI, Supabase/PostgreSQL, live place data, maps, and real AI generation are later phases. Do not place private API keys in frontend environment variables.
