# Database schema (MVP)

## `trips`

| Column | Type | Notes |
|---|---|---|
| `id` | `VARCHAR(36)` | Primary key, UUID generated by API |
| `destination` | `VARCHAR(180)` | Required, indexed |
| `start_date` | `DATE` | Required |
| `end_date` | `DATE` | Required; must not precede start date; maximum 14 days |
| `budget` | `FLOAT` | Required, positive |
| `currency` | `VARCHAR(3)` | ISO-like 3-letter currency code |
| `travelers` | `INTEGER` | 1–50 |
| `pace` | `VARCHAR(20)` | Relaxed, Balanced, Packed |
| `interests` | `JSON` / PostgreSQL JSON | List of interest values |
| `accommodation` | `VARCHAR(80)` | Accommodation preference |
| `itinerary` | `JSON` / PostgreSQL JSON | List of days, each containing activity objects |
| `created_at` | `TIMESTAMP WITH TIME ZONE` | Creation timestamp |
| `updated_at` | `TIMESTAMP WITH TIME ZONE` | Last update timestamp |

There is intentionally no `users` table yet. Authentication and row ownership should be added in the authentication phase before multiple users use this API.
